Woc小游戏制作之耄耋版翻金币
1.构建:Qt 6.8.3

2.玩法说明:经典翻金币玩法，点击一张图片其本身和周围图片都会翻转，玩家需要通过点击使所有图片都变成代表“正面”的那张。在这个游戏里飞行耄耋是反面，篮球耄耋是正面。

3.细节优化：对游戏配乐，按钮点击，页面切换，logo以及一系列小细节进行了一一些优化，基本玩法较为流畅
